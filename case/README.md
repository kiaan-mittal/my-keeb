# Case (Onshape)

Follow [Designing the Case](https://keeb.hackclub.com/docs/case-design).

## Plan

- Tray-mount bottom + optional 1.5–2mm plate
- Walls 2–3mm, base 3–5mm
- USB-C slot on the top wall (~10mm × 5mm)
- Window for the 0.91" OLED
- Hole for the EC11 shaft
- M3 heatset bosses
- **Split in the middle** with a tongue-and-groove — a 65% is ~305–330mm and will not fit a 220mm printer bed

## Export (required for submission)

From Onshape, right-click each part → Export → **STEP**, units **mm**, and commit the files here:

- `case-bottom-left.step`
- `case-bottom-right.step`
- `plate.step` (if you make one)
- `assembly.step` (optional, nice for review)

STLs are fine for printing but KEEB asks for STEP in the repo.
