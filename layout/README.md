# Layout

- [`kle.json`](kle.json) — paste into [Keyboard Layout Editor](http://www.keyboard-layout-editor.com/)
- [`layout.svg`](layout.svg) — planning sketch (also used in the README)
- [`matrix.md`](matrix.md) — row/column map for KiCad and RMK
- [`coordinates.csv`](coordinates.csv) — switch centers in mm for PCB placement

Regenerate the SVG, CSV, and KiCad starter files:

```bash
python3 scripts/generate_layout.py
```
